Screen with Python's own parser

ast, not regex

Every program is parsed with ast; import aliases resolve to canonical dotted names. from os import system and import subprocess as sp are the same calls.

8 categories, 35 rules

proc · fs · net · res · cred · priv · host · deser. Obfuscation like getattr(module, "attr") is matched against the same attribute tables.

fail-closed arithmetic

One high-severity hit refuses. Medium/low accumulate (45/18/3) and refuse at risk ≥ 55. No vibes, no model in the loop.

benign code passes

pandas groupby, matplotlib savefig, bounded loops, short sleeps — allowed, calibrated by the offline suite. Docstrings are not payloads.

receipt-ready

Every finding carries rule id, line/column and the matched source line. Every verdict is JSON you can re-run.

deterministic

Same source in, same verdict out. No network, no randomness, no API key. Standard library only.

Execution leaves the host

CagePilot host --HTTP--> Vultr VM (firewalled, ufw default-deny) | +-- vmagent.py (systemd, user `cage`) |-- CodeGuard re-screen on arrival +-- subprocess python3 -I job.py

defense in depth

The host screen runs first; only screened-clean code crosses the wire. The agent re-screens on arrival — a bypassed host screen still cannot execute high-risk code.

the receipt never lies

Bearer-token auth, 1 MiB body cap, timeout clamp. Unreachable agent or bad token is an explicit error — never a silent fallback to local execution.

verified, not asserted

122/122 offline assertions: benign corpus must pass, 21 refuse payloads pinned to exact rule ids, runner side-effect proofs, full HTTP contract, real vmagent over loopback, hostile-locale re-exec.
